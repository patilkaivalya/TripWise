# TripWise ✈️

**Plan a trip from flight search to a printable itinerary.** TripWise is a full-stack travel-planning web application that brings flight and hotel search, nearby discovery, budget estimates, and a day-by-day trip plan into one workflow.

## Overview

Planning a trip often means switching between flight-search sites, hotel listings, maps, restaurants, and spreadsheets. TripWise combines these steps into a single guided experience: enter a route and dates, compare flight options, choose a hotel, discover nearby places, review the estimated budget, and prepare a printable itinerary.

## Features

- **Location autocomplete** for choosing travel origins and destinations.
- **Flight search** for outbound and return options through SerpApi's Google Flights results, with available booking options for a selected itinerary.
- **Hotel search** for date-specific listings, with available rates, ratings, review counts, amenities, property details, and photos.
- **Nearby discovery** for restaurants and places to explore around the selected hotel's location.
- **Trip selection** to choose the flights, hotel, restaurants, and attractions to include in the plan.
- **Budget estimates** covering flights, hotel nights, food, local transport, and activities, with comparison against the user's budget.
- **Day-by-day itinerary** arranged from the selected trip dates and travel selections.
- **Print / Save as PDF** to export a clean copy of the itinerary from the browser.
- **Loading, empty, and error states** in search flows, with retry options where available.

> **Important:** Prices, availability, hotel photos, ratings, and booking links depend on external search results and may change or be unavailable. Budget amounts are estimates, not quotes. TripWise does not itself complete a purchase or confirm a reservation. The itinerary is assembled from the selected trip data and suggestions; it is not currently a response generated by a connected large language model.

## How it works

1. **Enter trip details.** Provide your origin, destination, travel dates, number of travellers, and budget.
2. **Search flights.** The React frontend sends requests to the Flask API, which uses SerpApi to retrieve available Google Flights results.
3. **Choose a hotel.** TripWise searches Google Hotels results for the destination and dates, including available pricing, ratings, amenities, and photos.
4. **Discover nearby places.** After a hotel is selected, the backend searches for nearby restaurants and attractions.
5. **Review the budget.** TripWise combines flight and hotel prices with estimates for food, local transport, and activities.
6. **Build and export the itinerary.** The app arranges a day-by-day plan from the trip selections and lets the user print or save it as a PDF.

### Request flow

The frontend does not call SerpApi directly. Search requests follow this path:

```text
React frontend
    |
    v
Flask REST API
    |
    v
SerpApi search services
    |
    v
Normalized results returned to React
    |
    v
Trip selections -> Budget estimate -> Day-by-day itinerary -> PDF export
```

## Getting started (Windows)

### Prerequisites

- Git
- Node.js and npm
- Python 3.10 or later
- A SerpApi account and API key for live search features

### 1. Clone the repository

```powershell
git clone https://github.com/patilkaivalya/TripWise.git
cd TripWise
```

### 2. Configure the backend

Open a **new terminal** in the project root and run:

```powershell
cd backend
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Create a file named `backend/.env` and add your own SerpApi credential. Use the exact environment-variable name read by `backend/config.py` (the example below uses `SERPAPI_API_KEY`):

```dotenv
SERPAPI_API_KEY=your_serpapi_api_key_here
```

If `backend/config.py` uses a different variable name in your checkout, keep that existing name. Do not add a real key to this README or commit it to Git.

Start the backend while the virtual environment is active and the terminal is in `backend/`:

```powershell
python app.py
```

The Flask API is configured for local development at `http://127.0.0.1:5000`.

### 3. Configure and start the frontend

Open a **second terminal** at the repository root (`TripWise/`) and run:

```powershell
npm install
npm run dev
```

Open the local URL printed by Vite. The current local setup has been used at `http://localhost:5174` and the frontend API client targets `http://127.0.0.1:5000/api`. Keep the configured development ports aligned with the backend CORS settings.

### 4. Try the app

1. Enter an origin, destination, departure and return date, traveller count, and budget.
2. Select an outbound flight and then a return option.
3. Search for hotels and choose one that fits your trip.
4. Select nearby restaurants and attractions.
5. Review the trip estimate and continue to the itinerary.
6. Use **Print / Save as PDF** to save a copy of the plan.

## Backend API overview

The backend groups endpoints by feature. The current frontend uses these routes:

| Method | Endpoint | Purpose |
| --- | --- | --- |
| `GET` | `/api/health` | Backend health check |
| `GET` | `/api/locations/autocomplete?q=...` | Location suggestions |
| `GET` | `/api/flights/autocomplete?q=...` | Flight-compatible city/airport suggestions |
| `POST` | `/api/flights/search` | Search outbound flight options |
| `POST` | `/api/flights/returns` | Find return options for a selected outbound flight |
| `POST` | `/api/flights/booking-options` | Retrieve available booking actions/options |
| `POST` | `/api/hotels/search` | Search hotels for the selected destination and dates |
| `POST` | `/api/discovery/search` | Find restaurants and places near the selected hotel |

For `POST` endpoints, send JSON request bodies. The route implementations contain the accepted fields and validation rules.

## Configuration and security

- Keep the SerpApi key in `backend/.env`; the frontend should never receive this secret.
- Keep `.env`, virtual environments, `node_modules`, and build output out of Git using `.gitignore`.
- Never paste API keys into source code, screenshots, issues, logs, or documentation.
- If a key is ever exposed, rotate it in the provider dashboard and update the local environment file.
- For deployment, set environment variables in the hosting provider's secret/configuration panel instead of uploading `.env`.
- The frontend and backend currently use local development URLs. These must be configured for the deployed frontend and backend before production use.

## Known limitations

- Search results depend on SerpApi availability, quotas, and provider response formats.
- The hotel search provider may limit the number of travellers in a single search; this implementation validates the supported range before sending a request.
- Prices and availability may change between search and booking. Always reconfirm with the provider before paying.
- Budget calculations are approximate and may not include all taxes, fees, tickets, or travel variations.
- The completed plan is saved in the current browser session, and the PDF is saved by the user through the browser print dialog. There is no account-based cloud trip storage in the current workflow.
- Itinerary times and meal/attraction suggestions are planning guidance, not reservations or guarantees of opening hours.

## Troubleshooting

### Hotel or flight search returns an error

- Confirm the backend terminal is running without import or configuration errors.
- Check that the API key is present in `backend/.env` and that the environment-variable name matches `backend/config.py`.
- Check your SerpApi account quota and the provider error returned in the backend terminal.
- Retry with a different date or location if the provider returns no results.

### Browser reports a CORS or network error

- Confirm Flask is running at `http://127.0.0.1:5000`.
- Confirm Vite is running at the expected local port (currently `5174`).
- Make sure the frontend base URL and the backend's allowed frontend origin match.

### Python reports a missing module

Activate the virtual environment from the `backend/` directory and run:

```powershell
pip install -r requirements.txt
```

### Hotel images do not load

Some image URLs returned by external providers can expire or fail to load. Retry a hotel search; if the issue persists, inspect the image fields returned by `/api/hotels/search` in the browser Network tab or backend response.
